# Exercícios de CORS (Node.js + Express)

## Antes de começar
1. Abra esta pasta no VS Code (`Arquivo > Abrir Pasta`).
2. Instale a extensão **Live Server** (Ritwick Dey).
3. Abra o terminal do VS Code (Ctrl + ') e rode uma vez:

```bash
npm install
```

## Como rodar cada exercício
Rode **um exercício por vez** (todos usam a porta 3000). Para parar o servidor, use Ctrl + C.

1. No terminal, inicie o backend, por exemplo `npm run ex1` (use ex1, ex2, ex3, ex4 ou ex5).
2. Clique com o botão direito no `index.html` da pasta do exercício e escolha **Open with Live Server**.
3. Abra o console do navegador (F12) para ver o resultado.

O arquivo `.vscode/settings.json` já configura o Live Server para `localhost:5500`.

Atenção: o Live Server, por padrão, abre em `127.0.0.1`, que é uma origem DIFERENTE de `localhost`. Como as configurações já deixam em `localhost`, funciona. Se aparecer erro de CORS inesperado, confira se a barra de endereço mostra `localhost:5500`.
